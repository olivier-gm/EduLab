# Logos de los métodos de pago

Coloca aquí los archivos con estos nombres exactos:

- Binance: `binance.svg`, `binance.png` o `binance.webp`.
- Banco de Venezuela (Pago Móvil): `bdv.svg`, `bdv.png` o `bdv.webp`.

La página `/plans` detecta los archivos en cada visita. Si existen varios
formatos, prioriza SVG, luego PNG y luego WebP. Si falta un logo, muestra únicamente el nombre del
método, sin imágenes rotas. No hace falta reiniciar el servidor.

Usa preferiblemente el símbolo de cada marca, con fondo transparente:
se muestra en un espacio de 36 × 24 píxeles sin deformarlo.
